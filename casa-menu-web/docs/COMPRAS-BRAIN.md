# COMPRAS-BRAIN — marcas para el carrito Tipti

Usar SOLO al armar el carrito, nunca al planear el menu. Si un item no esta aqui, no adivinar: marcar y preguntar a Emilio.

Tienda Tipti: Supermaxi. Canal: Tipti (tipti.ec o la app). Mercado fresco no entra.

Sustitucion: si no hay stock de la marca preferida, listar alternativa y esperar. Nunca cambiar de proteina ni de alergeno.

## Mercado (NO Tipti)

Pollo, res, pescado, camarones, salmon, verdura de encurtidos, limon, platano verde, yuca, guineo, manzana, aguacate, ajo. Lista en `shopping.mercado`. Se compra aparte el dia de mercado (miercoles del ciclo).

## Como actualizar este archivo

Cuando Emilio diga "marca X de ahora en adelante", agregar o sustituir la fila. El bot no cambia marcas por su cuenta.
